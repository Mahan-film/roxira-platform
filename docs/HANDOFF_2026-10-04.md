## 6. Gotchas learned
- The Claude desktop app leaves `core.bare=true` in `.git/config` when it cleans agent worktrees. Run `git config core.bare false` at the START of every bash chain before git; launch agents one at a time; if the owner sees "must be run in a work tree" tell them to run `git config core.bare false` in the repo.
- Test files must not run code at import (quarantine guard): load scripts inside fixtures; no module-level calls or concatenated constants.
- Agents only run their own tests: ALWAYS run `local_ci.sh` in their worktree before opening the PR.
- Never change OpenCode `enabled_providers` without checking `~/.config/opencode/opencode.json` providers (`pool`, `omniroute`).
- gitleaks missed provider-specific keys: scan with `scripts/dev/local_ci.sh` provider-key step and `export_public.py` before any public push; helper scripts must never echo env lines.
- System Python on the Mac lacks CA certs: scripts use certifi (`pip install certifi`).
- Iran: Anthropic's supported-country list does not include Iran (account matter for the owner); GitHub/US services may restrict; Groq blocks the owner's account; keep local fallbacks.
