# راهنمای Antigravity برای مالک (به‌روز ۲۰۲۶-۱۱-۲۳)

این تنها راهنمایی است که برای کار با Antigravity لازم داری. دستورها را از همین‌جا کپی کن.

## ۱. قبل از شروع
- SSD خارجی باید وصل باشد (پارتیشن `ssd`). worktreeها و cacheهای laneها در `/Volumes/ssd/roxira-work` ساخته می‌شوند و دیسک مک پر نمی‌شود.
- تا وقتی چتی در حال کار است، SSD را جدا نکن. اگر لازم شد، اول همهٔ چت‌ها را متوقف کن.
- پارتیشن `share mac w` از نوع exFAT است و برای کار با git مناسب نیست. laneها از آن استفاده نمی‌کنند.

## ۲. laneهای مک (حداکثر ۸ چت هم‌زمان)
تا وقتی Antigravity روی لپ‌تاپ آماده نشده، همهٔ این laneها روی مک اجرا می‌شوند. هر lane در یک چت جدا اجرا می‌شود. دستورش را در Terminal بزن، بعد در چت تازهٔ Antigravity ⌘V بزن.

| lane | کار | وضعیت |
|---|---|---|
| L8 | تعمیر PRهای گیرکرده (blocker، CI قرمز، conflict) | **اول این را شروع کن**؛ برای تمام‌کردن PRهای باز از همه مهم‌تر است |
| L12 | بستهٔ تصمیم برای PRهای حساس، مدارک | در حال اجرا |
| L1 | زیرساخت و دیسک | در حال اجرا |
| L2 | فاکتور و واردات | در حال اجرا |
| L3 | امنیت و داده | در حال اجرا |
| L4 | قاضی هوشمند | در حال اجرا |
| L5 | هستهٔ حسابداری (اولویت ۱) | جدید روی مک |
| L6 | بسته‌های کشور | در حال اجرا |

L9 (صفحه‌های خرید و فروش)، L10 (صفحه‌های مالیات و گزارش) و L11 (تست) وقتی شروع می‌شوند که لپ‌تاپ آماده شود یا PRهای باز به کمتر از ۱۵ برسند. L7 فقط مال لپ‌تاپ است.

دستور کپی هر lane (فقط شمارهٔ lane را عوض کن):

```bash
cd ~/Developer/roxira-platform && git fetch -q origin && git show origin/main:docs/antigravity/prompts/L8.txt | pbcopy
```

```bash
cd ~/Developer/roxira-platform && git fetch -q origin && git show origin/main:docs/antigravity/prompts/L5.txt | pbcopy
```

اگر یک lane نوشت «BLOCKED: disk»، اول ببین SSD وصل است یا نه، بعد همان پرامپت را دوباره بده.

## ۳. وقتی یک چت تمام شد یا خیلی طولانی شد
- اگر چت گزارش REPORT داد و ایستاد، همان پرامپت را دوباره در **همان چت** بده تا دور بعد را شروع کند.
- اگر چت خیلی طولانی شد یا گفت context پر شده، اول `/compact` بزن و بعد همان پرامپت را بده. فقط اگر بعد از این هم کار نکرد، چت تازه باز کن.

## ۴. دستورهای اسلش Antigravity: کدام به کار ما می‌آید

| دستور | استفاده کنیم؟ | چرا |
|---|---|---|
| `/compact` | **بله** | چت طولانی را خلاصه می‌کند و lane بدون چت تازه ادامه می‌دهد. |
| `/plan` | **بله، فقط برای ردیف بزرگ** | برای L5 (حسابداری) و L3 (امنیت) قبل از کار بزرگ: «/plan» و بعد پرامپت. |
| `/browser` | **بله، فقط L9، L10 و L11** | صفحه‌ای را که ساخته‌اند روی localhost باز می‌کنند و چک می‌کنند. به سایت production و حساب واقعی نروند. |
| `impeccable` (skill) | **بله، فقط L9 و L10** | برای طراحی و پرداخت صفحه‌های frontend. |
| `/learn` | اختیاری | اگر lane اشتباهی کرد و درستش کردی، `/learn` تا تکرار نکند. قانون اصلی همچنان `docs/agents/LESSONS.md` است. |
| `/teamwork` و `/boost` | **فعلاً نه** | چند agent را با هم در یک پوشه اجرا می‌کنند. سهمیه را زود تمام می‌کنند و فایل‌های هم را خراب می‌کنند. ما همین کار را با laneهای جدا انجام می‌دهیم. |
| `/swarm` | **نه** | خودش نوشته «Quota Heavy». سهمیهٔ یک روز را در چند دقیقه می‌خورد. |
| `/schedule` و `automation` | **نه** | قانون ما این است که Antigravity خودکار اجرا نشود و فقط تو آن را اجرا کنی. |
| `/grill-me` | نه | برای مصاحبه با توست؛ ما تصمیم‌ها را در issue می‌گیریم. |
| `generative_ui`، `plugin`، `migrate-agent-settings`، `migrate-workflows`، `antigravity-guide` | نه | به کار ما ربطی ندارند. |

حالت **Turbo** را روشن نگه دار. lane بدون پرسیدن دستور اجرا می‌کند و قانون‌های خودش جلوی merge و دسترسی به production را می‌گیرند.

## ۵. لپ‌تاپ لینوکس
- وقتی Antigravity روی لپ‌تاپ کار کرد، L9، L10 و L11 به لپ‌تاپ می‌روند و مک سبک‌تر می‌شود.
- Claude روی لپ‌تاپ «باکس‌هاب» است و پرامپتش `docs/hub/BOX_HUB_CLAUDE.md` است. ارتباط مک‌هاب و باکس‌هاب فقط از طریق GitHub است: یادداشت‌های «HUB -> BOX» روی issue 592 و پرسش‌ها روی issue 965. مک‌هاب به لپ‌تاپ SSH نمی‌زند. این قانون امنیتی خود توست و برای این است که یک حساب، دستگاه دیگر را کنترل نکند.
- برای اینکه Claude لپ‌تاپ کاری را روی لینوکس انجام دهد، مک‌هاب یک یادداشت «HUB -> BOX» روی issue 592 می‌گذارد. تو فقط در چت Claude لپ‌تاپ بنویس: «آخرین یادداشت HUB -> BOX را روی issue 592 بخوان و انجام بده».

## ۶. کارهایی که فقط تو می‌توانی بکنی
- برای PRهای حساس (migration، پرداخت، auth، deploy، workflow، nginx، compose) جملهٔ تأیید بده. L12 برای هر کدام بستهٔ ساده‌ای می‌نویسد و مک‌هاب آن‌ها را یکجا از تو می‌پرسد.
- SSD را وصل نگه دار.
- **فایل‌های حساس روی پارتیشن exFAT:** روی `share mac w` دو فایل با نام کلید و تنظیمات محرمانه هست. exFAT دسترسی را محدود نمی‌کند و هر دستگاهی که دیسک به آن وصل شود آن‌ها را می‌خواند. اگر نسخهٔ اصلی در جای امن مک هست، این دو کپی را خودت پاک کن یا به پوشهٔ رمزگذاری‌شده ببر. مک‌هاب آن‌ها را نخوانده و دست نمی‌زند.
