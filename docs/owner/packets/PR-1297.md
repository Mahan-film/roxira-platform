# بستهٔ تصمیم PR #1297

- **عنوان:** اعتبارسنجی کد بستهٔ کشور و ارز دفتر در تنظیمات و ثبت `CountryPackInterceptor` (`T338` / `#1287`)
- **وضعیت و سرشاخه:** باز | `a99683ef` | `MERGEABLE`

## چه چیزی را تغییر می‌دهد
- `CountryPacksModule` را `@Global()` می‌کند و `CountryPackInterceptor` را به‌عنوان `APP_INTERCEPTOR` ثبت می‌کند تا در هر درخواست HTTP بستهٔ کشور و ارز مستأجر مشخص شود.
- در `TenantsService.updateSettings()` بررسی می‌کند که کد کشور در `CountryPackRegistry` ثبت شده باشد و کد ارز دقیقاً با `pack.locale.currency.code` بخواند (در غیر این صورت به‌صورت fail-closed خطای `400` می‌دهد).
- در فرم ثبت‌نام فرانت‌اند (`onboarding-wizard.tsx`) انتخاب بستهٔ کشور و ارز و هشدار قفل‌شدن دائمی پس از نخستین سند ثبت‌شده را اضافه می‌کند.

## چه چیزی ممکن است در production خراب شود
- مستأجرهایی که قبلاً با کد کشور یا ارزی خارج از فهرست بسته‌های ثبت‌شده ایجاد شده‌اند، هنگام تغییر تنظیمات با خطای `BadRequestException` روبه‌رو می‌شوند.
- ثبت `APP_INTERCEPTOR` روی تمام درخواست‌های HTTP اجرا می‌شود؛ اگر در مسیرهای عمومی یا بدون مستأجر با خطا مواجه شود می‌تواند روی کل API اثر بگذارد.
- این PR به `modules/country_packs/**` (محدودهٔ هستهٔ B1) دست می‌زند.

## نیاز به restart یا کار دستی
- بله: rebuild و restart سرویس‌های NestJS و Next.js هنگام deploy.
