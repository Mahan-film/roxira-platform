# فروش فوری بی‌نام (پایانه فروش / POS)

از منوی **فروش** وارد **پایانه فروش** (`/app/invoicing/pos` — با عنوان «پایانه فروشگاهی و صندوق (POS)») شوید.

1. به‌صورت پیش‌فرض مشتری روی **«مشتری گذری»** تنظیم شده است و می‌توانید بدون انتخاب طرف‌حساب فروش را ثبت کنید (یا نام دلخواه مشتری را تا ۱۲۰ نویسه بنویسید).
2. کالاها را با **کد / بارکد** یا شرح، تعداد و قیمت واحد اضافه کنید.
3. در صورت قطع اینترنت، وضعیت به **«آفلاین (بدون اینترنت)»** تغییر می‌کند و فروش‌ها در صف محلی ذخیره می‌شوند تا پس از برقراری ارتباط (**«آنلاین (متصل)»**) همگام‌سازی شوند.
4. پس از ثبت فروش، امکان چاپ رسید صندوق وجود دارد. (برای جزئیات بیشتر صندوق‌ها و تسویه، راهنمای `41-cash-boxes-and-pos.md` را ببینید.)
