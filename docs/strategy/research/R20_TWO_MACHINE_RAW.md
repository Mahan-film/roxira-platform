### Concrete Technical Bugs Found in Stage 1 Snippets

* **Snippet #4 (SQLite `file_locks`):** `LIKE fl.path_prefix || '%'` treats `_` and `%` in directory names as SQL wildcards, only supports a single prefix per task (fails on multi-directory PRs), and deadlocks on shared monorepo roots (`package.json`, `pnpm-lock.yaml`, schema files). Replace with normalized path arrays stored in a join table (`task_scopes`) and prefix comparison using `SUBSTR(a, 1, LENGTH(b)) = b`.
* **Snippet #5 (`pick-runner` fallback & action pinning):** Checking `status == "online"` without checking `busy == false` (and without accounting for the 5–15 s recycle window between ephemeral JIT containers) causes false fallbacks to `ubuntu-latest`, silently draining the $12 cap. Additionally, `actions/checkout@v4` and `actions/create-github-app-token@v1` use mutable tags instead of pinned 40-char commit SHAs.
* **Snippet #7 (Production `deploy/*` tag guard):** `git tag --list 'deploy/*' --sort=-v:refname | head -n1` followed by `tag -v || exit 1` creates a **denial-of-service vector**: pushing any unsigned tag that sorts higher (e.g., `deploy/99999999-1`) halts all future production deploys until manually deleted. Iterate over tags in descending version order and select the newest tag that *passes* `tag -v`.
* **Snippet #2 (Claude `--allowedTools` shell bypass):** Allowing `Edit`/`Write` alongside `Bash(pnpm test *)` or `Bash(pytest *)` is not a code-execution boundary—the agent can edit a test file or `package.json` script and execute arbitrary code inside the test runner.

## 2. What the Report Missed (12–24 Month Failure Modes)

1. **Code Exfiltration Through the "Allowed" Xray Egress Proxy (Agent Security)**
`nftables` blocks RFC1918 LAN traffic and forces builder UIDs through Xray, but Xray is an *open internet proxy*, not a domain allowlist. A prompt-injected agent (or poisoned npm/PyPI `postinstall` script) running via `pnpm test` can curl your entire proprietary Roxira codebase to an external server via Xray—or encode secrets into outbound LLM prompts. *Fix:* Terminate builder egress at a strict domain-allowlist HTTP proxy (e.g., Squid or Envoy allowing only `127.0.0.1:8787` and pinned package registries, with `CONNECT` blocked everywhere else).
2. **Container Escape in CI Slot 2 (`ephemeral-pg`) (Agent/CI Security)**
Slot 2 exposes a rootless Docker socket to run Docker Compose for PostgreSQL/Valkey/Qdrant tests. Any workflow step or malicious dependency running inside Slot 2 can spawn a privileged container inside the rootless namespace, inspect sibling containers, or read anything accessible to the rootless Docker UID. *Fix:* Never run untrusted PR code and the Compose daemon under the same privilege domain; pre-boot ephemeral DB services via GitHub `services:` or run Slot 2 inside a dedicated throwaway VM (Incus/QEMU) if third-party PRs or external contractors ever touch the repo.
3. **Consumer Claude Subscription Ban Risk on Unattended `claude -p` (AI Provider Risk)**
Stage 1 rightly bans consumer Antigravity for unattended loops, yet still proposes running unattended `claude -p` on a consumer Claude Pro/Max subscription (Account B). Anthropic already restricted OAuth token extraction in early 2026; tightening consumer subscription ToS against headless cron/daemon loops is a high-probability 12-month event that could suspend Account B overnight. *Fix:* Treat Account B's subscription as interactive/burst-only or prepare a one-env-var switch to pure API-key billing (`ANTHROPIC_API_KEY` + OpenRouter/LiteLLM) with hard monthly spend caps.
4. **AI Provider Quota Decay & Price Spikes Breaking Unit Economics (AI Provider Risk)**
Promotional flash-model pricing (including the noted 2× jump on Jan 1, 2027) and silent weekly rate-limit tightenings can abruptly multiply token burn across 7 lanes. Without a per-PR token ceiling and a "circuit breaker" that automatically pauses Tier 0/low-priority lanes when daily spend hits a threshold, a retry loop on a flaky test can drain a month's budget in one night.
5. **Catastrophic Hardware Failure of the Single CI + Phone + Control-Plane Box (Losing the Only CI Machine)**
An i7-8550U laptop is 2017–2018 consumer silicon. Running 24/7 with heavy Docker layer churn, git worktrees, and thermal cycling will eventually kill its NVMe SSD, fan, power jack, or motherboard. Because Stage 1 co-locates **five** critical workloads on it (`roxira-orch`, CI runners, merge gate, LiveKit/SIP phone stack, and weekly PG restore drills), one hardware failure takes down your customer-facing AI phone line *and* your entire engineering pipeline simultaneously. *Fix:* Decouple the production-facing LiveKit/SIP phone stack from the CI/agent laptop, and codify `roxira-ci` in an Ansible playbook so a replacement mini-PC or VPS can be provisioned in under 60 minutes.
6. **GitHub Plan & API Squeeze Without Metadata Backups (GitHub Plan Changes)**
A nightly `git clone --mirror` backs up Git commits, **not** GitHub Issues, PR review threads, labels, or Actions workflows. If GitHub reinstates the $0.002/min self-hosted runner fee, cuts Free org Actions/API limits, or locks your org over a billing/sanctions/abuse flag, your entire operational backlog and audit trail are stranded. *Fix:* Schedule a weekly GitHub metadata export (Issues, PRs, comments, releases via `gh` API or `github-backup` to JSON inside your Restic backup).
7. **Production Migration Locks & Zero-Rollback Deploy Loop (Production Reliability)**
The 5-minute pull timer runs `pg_dump`, applies migrations, and restarts containers, but lacks: (a) an automated post-deploy healthcheck + automatic container rollback on failure, (b) lock-timeout guards (`SET lock_timeout = '5s'`) so an `ALTER TABLE` doesn't freeze live POS/invoicing traffic, and (c) protection against the `deploy/*` unsigned-tag DoS bug in Snippet #7.
8. **Silent ERP/Compliance Regressions & Multi-Tenant RLS Leaks (Domain Risk)**
Cross-model LLM review is strong on local code quality and weak on cross-cutting invariants—double-entry ledger balance, FIFO/BOM rounding, GoBD immutability, ZATCA/MyInvois XML compliance, and PostgreSQL Row-Level Security (RLS) tenant isolation. Over 12–24 months of autonomous PRs, a single missing `SET LOCAL app.tenant_id` or subtle rounding drift will cause a severe customer data leak or accounting audit failure. *Fix:* Add deterministic property-based invariant tests (trial-balance zero-sum, cross-tenant RLS fuzz test) as mandatory CI gates for every Tier 1/2 PR.
9. **Backup Ransomware / Same-Account Blast Radius on Cloudflare R2 (Data Safety)**
If both production (`pg_dump`) and `roxira-ci` (`restic-box`) push to the same Cloudflare account without R2 Object Lock / retention rules, a compromised token or accidental `restic forget --prune` misconfiguration can wipe both live data and backups. *Fix:* Enforce append-only / write-once bucket policies (no `DeleteObject` permission on production's R2 token) and test restoring from a clean-room host.
10. **Scaling Past 2 Founders & Enterprise Customer Security Questionnaires (12–24 Month Business Risk)**
In 12–24 months, hiring engineer #3–#5 or onboarding a German/Gulf SMB customer with a GDPR/security questionnaire will hit four walls: (a) NetBird Cloud Free caps at 5 users, (b) building production code on a residential laptop behind a domestic ISP fails basic SOC2/ISO-27001 physical/network controls, (c) sending proprietary code via consumer AI plans lacks a Data Processing Agreement (DPA) / Zero Data Retention (ZDR), and (d) there is no SBOM or signed provenance (SLSA/Cosign) for deployed artifacts.
11. **Monorepo Chokepoint Serialization & Disk Exhaustion on `roxira-ci` (Orchestration Debt)**
Multiple parallel lanes touching `pnpm-lock.yaml`, `packages/shared`, or database schemas will constantly collide on `file_locks`, collapsing effective concurrency back to 1. Simultaneously, per-worktree `node_modules` and orphaned worktrees from crashed runs will exhaust the laptop's root SSD unless you use `pnpm`'s content-addressable store (`--prefer-offline`) and a hard disk-usage circuit breaker (pausing claims above 80% disk usage).
12. **Dependency Slopsquatting & Unpinned Supply Chain (Agent Security)**
Autonomous agents occasionally invent non-existent package names (targeted by attackers via slopsquatting) or upgrade packages with malicious `postinstall` hooks. Stage 1 runs OSV-Scanner (which only catches *known* CVEs), leaving newly published malicious packages undetected. *Fix:* Block `package.json` / `pyproject.toml` dependency additions in Tier 0 (promote any new dependency to Tier 1 human approval) and run `pnpm install --ignore-scripts` in builder worktrees.

### Phased Execution Roadmap

* **This Week (Days 1–5 — Zero-Downtime Cutover & Security Baseline)**
1. Run live checks on the **UNVERIFIABLE** items in Section 1 (GitHub Actions billing table, NetBird direct reachability from `roxira-ci`, `gitea-mq` repo health, Claude/Gemini current CLI flags & pricing).
2. Flatten GitHub secrets to repo-level, deploy read-only production Deploy Key, and implement the **corrected** signed-tag loop (newest *validly signed* `deploy/*` tag) + `lock_timeout` guard on production.
3. Add Gitleaks (MIT binary, SHA256-pinned), Semgrep CE, and OSV-Scanner to CI; pin all GitHub Actions (`checkout`, `create-github-app-token`) to full 40-char commit SHAs.
4. Deploy NetBird Cloud Free + Xray SOCKS5 Reverse SSH fallback; commit `AGENTS.md` + `CLAUDE.md` shims; flip repo private.


* **This Month (Weeks 2–4 — Ephemeral CI, Hardened Orchestrator & Backups)**
1. Upgrade CI to ephemeral JIT rootless Docker; fix `pick-runner` to check `status=="online"` with a 15 s retry so JIT recycle windows don't burn the $12 cap.
2. Deploy `roxira-orch` using a normalized `task_scopes` join table (replacing the buggy `LIKE` query), disk-usage circuit breaker (80%), and strict domain-allowlist egress proxy in front of Xray for builder UIDs.
3. Enforce `pnpm install --ignore-scripts` in builder worktrees and route any `package.json`/`pyproject.toml` change to Tier 1 human review.
4. Enable append-only R2 tokens (no `DeleteObject` from prod), weekly GitHub Issues/PR JSON export, Sunday PG 17 restore drills, and 40–80% battery cap + router mini-UPS.


* **Month 3 (Resilience, Domain Invariants & IaC)**
1. Codify `roxira-ci` in an Ansible playbook and run a timed bare-metal/VM recovery drill (target: under 60 min from R2 backup to live runner + orchestrator).
2. Add deterministic ERP invariant tests (double-entry trial balance, cross-tenant PostgreSQL RLS isolation fuzzing) as mandatory Tier 1/2 CI gates.
3. Decouple the LiveKit/SIP phone stack off `roxira-ci` onto a dedicated VPS before onboarding live phone-line customers.


* **Month 6 (Commercial Scale & Compliance Readiness)**
1. Migrate unattended builder lanes fully onto commercial API-key / DPA-covered endpoints (retiring consumer subscriptions from headless automation).
2. Re-evaluate GitHub Free vs. GitHub Team ($4/user/mo) or dedicated Hetzner CI runner once revenue supports $8–$20/mo, eliminating home-laptop operational overhead.
