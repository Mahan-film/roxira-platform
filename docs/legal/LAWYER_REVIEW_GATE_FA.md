# برگه بازبینی وکیل برای دروازهٔ دقت پاسخ‌های حقوقی

تاریخ تولید: 2026-10-12. وضعیت همهٔ سؤال‌ها: `draft_needs_lawyer` (هنوز هیچ‌کدام توسط وکیل تأیید نشده است).

## هدف

این ۷۰ سؤال (۵۰ سؤال توسعه و ۲۰ سؤال کنار گذاشته‌شده) از روی خود مواد پایگاه قانون (`iran_laws_v3`، منبع ekhtebar.ir به‌جز قانون اساسی) نوشته شده‌اند. با آن‌ها پس از هر تغییر در متن قوانین یا پرامپت، دقت سامانه به‌صورت عددی اندازه‌گیری می‌شود. اگر پاسخ مورد انتظار غلط باشد، اندازه‌گیری هم بی‌ارزش می‌شود؛ پس به نظر وکیل نیاز داریم.

## چطور بازبینی کنید (برای هر سؤال، حدود ۳۰ ثانیه)

1. سؤال را بخوانید: آیا یک شهروند واقعاً چنین چیزی می‌پرسد و آیا سؤال مبهم یا چندپاسخ نیست؟
2. ستون «ماده مورد انتظار» را ببینید: آیا مادهٔ ذکرشده همان جایی است که جواب سؤال را می‌دهد؟
3. ستون «عبارات الزامی» را ببینید: این عبارات باید در متن ماده باشند و در پاسخ درست هم دیده شوند (عدد، مهلت، مجازات).
4. نکتهٔ مهم: آیا ماده هنوز معتبر است؟ (نسخ‌شده، اصلاح‌شده یا جایگزین‌شده؟) متن این برگه از ekhtebar.ir است که منبع غیررسمی است.
5. در ستون «تأیید» یکی را علامت بزنید: `بله` (همه‌چیز درست)، `خیر` (سؤال یا ماده غلط است)، `اصلاح` (با توضیح در ستون یادداشت).

## چطور تأییدشده ثبت می‌شود

فایل سؤالات: `data/eval/chat_golden/legal_gate_2026-10-12.json`. برای هر سؤالی که وکیل «بله» زده، مقدار `status` از `draft_needs_lawyer` به `lawyer_verified` تغییر می‌کند؛ برای «خیر» به `lawyer_rejected` (و سؤال از محاسبهٔ نهایی کنار می‌رود). وکیل فقط این برگه را با علامت‌ها برمی‌گرداند؛ تغییر فایل را مسئول فنی انجام می‌دهد. نمونه فرمان (شناسه‌های تأییدشده را جایگزین کنید):

```bash
python3 - <<'PY'
import json
p = 'data/eval/chat_golden/legal_gate_2026-10-12.json'
d = json.load(open(p, encoding='utf-8'))
ok = {'lg-taz-618', 'lg-lab-7'}        # شناسه‌های «بله»
no = set()                              # شناسه‌های «خیر»
for c in d['cases']:
    if c['id'] in ok: c['status'] = 'lawyer_verified'
    if c['id'] in no: c['status'] = 'lawyer_rejected'
json.dump(d, open(p, 'w', encoding='utf-8'), ensure_ascii=False, indent=1)
PY
```
