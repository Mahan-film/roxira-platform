## فایل‌های نمونه‌ای که برای پروفایل نرم‌افزارهای ایرانی لازم است

هیچ پروفایلی برای سپیدار، همکاران سیستم، راهکاران یا محک ادعا نمی‌شود، چون خروجی واقعی آن‌ها را نداریم. برای ساخت هر پروفایل این خروجی‌ها از یک نسخهٔ واقعی لازم است (داده می‌تواند آزمایشی یا ناشناس‌شده باشد):

| نرم‌افزار | فایل‌های لازم |
|---|---|
| سپیدار | خروجی اکسل یا CSV: سرفصل حساب‌ها، تراز آزمایشی، دفتر روزنامه با چند سند، مانده‌های افتتاحیه، اشخاص، کالا و موجودی |
| همکاران سیستم | خروجی اکسل یا CSV: سرفصل حساب‌ها، تراز آزمایشی، دفتر روزنامه با چند سند، مانده‌های افتتاحیه، اشخاص، کالا و موجودی |
| راهکاران | خروجی اکسل یا CSV: سرفصل حساب‌ها، تراز آزمایشی، دفتر روزنامه با چند سند، مانده‌های افتتاحیه، اشخاص، کالا و موجودی |
| محک | خروجی اکسل یا CSV: سرفصل حساب‌ها، تراز آزمایشی، دفتر روزنامه با چند سند، مانده‌های افتتاحیه، اشخاص، کالا و موجودی |

همراه هر فایل، نسخهٔ نرم‌افزار و مسیر منوی خروجی را هم بنویسید. برای OCR نیز چند عکس و PDF اسکن‌شدهٔ واقعی فارسی لازم است تا دقت اندازه‌گیری شود.
