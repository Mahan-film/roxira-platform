## 3. How changes reach production (fully automatic)

1. Work on a branch from `origin/main` in a worktree. Push with `SKIP_LOCAL_CI=1 git push ...` (the local
   pre-push CI hook has two unrelated failures; run the tests relevant to your change yourself).
2. `gh pr create --repo Mahan-film/roxira-platform ...` then **you merge**:
   `gh pr merge N --repo Mahan-film/roxira-platform --squash --admin --delete-branch`.
3. Within ≤5 min the server timer deploys `origin/main`: copies `scripts/ops/deploy_local.sh` from the
   target commit, runs **migrate (pg_dump backup first) if migrations changed**, rebuilds changed
   services, smoke tests, legal retrieval gate, **auto-rollback** on failure; a failed SHA is never
   retried (a newer commit retries). Status: `ssh roxira-prod cat /root/deploy-state/autodeploy-last.json`,
   logs `/var/log/roxira-autodeploy/`. Pause: `touch /opt/roxira_platform/.deploy-freeze`.
4. Things NOT covered by autodeploy (run them yourself over ssh after the commit is on the server):
   key pool re-render (`install.sh --apply`), research service, Qdrant collection switch (`.env`
   `LIGHTRAG_QDRANT_COLLECTION` + `docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate enterprise_app`; back up `.env` to `/root/env-backups/` first).
5. Migrations: new files in `output_apps/enterprise_hub/migrations/` with a unique timestamp after
   `1789190000000`; **check every table/index/column name against the live DB read-only** before merging
   (psql via `docker exec -i roxira_postgres_prod sh -c 'psql -U $POSTGRES_USER -d enterprise_db'`).

## 4. Server agents (your workers)

```
ssh roxira-prod 'cat > /tmp/t-x.md' < local_task_file.md
ssh roxira-prod 'cd /opt/roxira_platform; setsid nohup scripts/infra/server_agents/run_task.sh \
  --model ds-flash            # or: --gateway --public  (free tier) [--tier light]
  --task-file /tmp/t-x.md --scope <dir>/ [--scope ...] --slug x --timeout 3600 \
  > /root/agent-x.out 2>&1 < /dev/null &'
```
- OpenCode in an isolated worktree under `/var/lib/roxira-agents/worktrees/<date>-<slug>`; the runner
  commits; edits only inside `--scope`; `data/` scopes are refused; no network, no npm/tsc/jest.
- Get the result: `ssh roxira-prod 'W=$(ls -d /var/lib/roxira-agents/worktrees/*-x | tail -1); git -c safe.directory="*" -C $W format-patch -1 --stdout' > x.patch`, then `git am` on a fresh branch
  in **`.wt/keypool`** (hub worktree with backend + frontend `node_modules` installed), run
  `npx tsc --noEmit -p tsconfig.json` and `npx jest` in `output_apps/enterprise_hub`,
  `./node_modules/.bin/tsc --noEmit -p .` in `frontend`, targeted pytest files only, fix, amend, PR, merge.
- Free tier (`--gateway --public`) finishes big tasks incompletely ~half the time (Groq 8k TPM): give it
  small tasks; use `ds-flash` (cheap) for large inputs or multi-file code; re-run with a note listing
  what is missing when output is partial. Launch parallel agents ~15 s apart (worktree lock).
- Typical agent bugs seen: wrong relative import paths, missing callers after signature changes,
  `x` vs `x[]` return types, tests with invalid fixture data, marketing copy with false claims.
