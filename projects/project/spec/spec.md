## پیشنهاد فناوری برای: [بریف] میکروسایت ایستا پرسش‌های متداول حقوقی فارسی

وضعیت تحقیق: `SUCCESS` — هزینه: $0.0108

### خلاصه مدیریتی
این پروژه یک میکروسایت ایستای پرسش‌های متداول حقوقی فارسی با ۱۰ پرسش، جستجوی درون‌صفحه‌ای، طراحی راست‌به‌چپ با فونت وزیرمتن، حالت تیره/روشن و هشدار عدم قطعیت مشاوره حقوقی است که بدون پایگاه داده و ورود کاربر و با محتوای Markdown اجرا می‌شود. توصیه‌های هر سه لایه فنی (UI/UX، Frontend، Infra/Server) به‌طور هم‌راستا بر استک ترجیحی مالک یعنی Next.js با خروجی ایستا، Tailwind و shadcn/ui متمرکز شده‌اند و لایه Cost/FinOps نیز میزبانی استاتیک روی CDN با سطح رایگان را تأیید می‌کند. بالاترین هم‌افزایی در انتخاب Next.js به‌عنوان چارچوب فرانت‌اند و shadcn/ui به‌عنوان کتابخانه رابط کاربری دیده می‌شود، در حالی که GitHub Pages به‌عنوان ساده‌ترین گزینه میزبانی ایستا پیشنهاد شده است. هیچ تضاد بنیادینی بین لایه‌ها وجود ندارد، اما نکات اجرایی مانند تنظیمات دستی RTL، پشتیبانی از فونت وزیرمتن و صحت‌سنجی خروجی ایستا با Playwright باید در پیاده‌سازی لحاظ شود. هزینه ماهانه کل برای یک استارتاپ کوچک در محدوده ۰ تا ۵ دلار برآورد می‌شود که عمدتاً شامل دامنه و ترافیک کم است.

**برآورد هزینه ماهانه کل استک:** ۰ تا ۵ دلار (شامل هزینه دامنه و ترافیک کم؛ میزبانی در سطح رایگان)

### ریسک‌های بین‌لایه‌ای
- نیاز به تنظیمات دستی برای پشتیبانی کامل RTL و فونت وزیرمتن در shadcn/ui و Tailwind که بین لایه‌های UI/UX و Frontend مشترک است.
- ضرورت صحت‌سنجی سازگاری خروجی ایستای Next.js با میزبانی GitHub Pages و تست خودکار Playwright که بین لایه‌های Frontend و Infra/Server و تست مشترک است.
- نبود شواهد قیمت‌گذاری دقیق در منابع لایه Cost/FinOps که می‌تواند برآورد هزینه ماهانه را با عدم قطعیت مواجه کند و بر تصمیم‌گیری لایه Infra/Server اثر بگذارد.
- وابستگی به سهمیه رایگان ارائه‌دهنده میزبانی (GitHub Pages یا Cloudflare Pages) که در صورت رشد ترافیک می‌تواند هزینه‌های پنهان ایجاد کند و بین لایه‌های Infra/Server و Cost/FinOps مشترک است.

### گزینه‌ها به تفکیک لایه

### رابط و تجربه کاربری (UI/UX) (UI/UX)
- **Laws of UX** — امتیاز پذیرش: 8/10، هزینه ماهانه: 0 (استفاده از اصول عمومی بدون هزینه مجوز)، ریسک: منبع صرفاً اصول تجربی UI/UX را فهرست می‌کند و کد یا کامپوننت آماده ارائه نمی‌دهد.، اعمال مستقیم اصول آن نیازمند ترجمه به پیاده‌سازی Next.js/Tailwind است.، برای الزامات خاص فارسی و RTL راهنمای اختصاصی ندارد.
- **Design System Documentation for LLM (رویکرد مقاله UX Collective)** — امتیاز پذیرش: 4/10، هزینه ماهانه: 0 تا 20 (در صورت استفاده از ابزارهای طراحی رایگان یا پایه)، ریسک: محتوای خزش‌شده فقط مقدمه و توضیح کلی دارد و جزئیات فنی کامل در دسترس نیست.، رویکرد مستندسازی برای LLM ممکن است برای تیم کوچک بیش از حد سنگین باشد.، وابستگی به ابزارهای خارجی مانند Figma و Medium در محتوای منبع دیده می‌شود.
⭐ **shadcn/ui** — امتیاز پذیرش: 7/10، هزینه ماهانه: 0 (کتابخانه متن‌باز، بدون هزینه مجوز)، ریسک: در منابع خزش‌شده هیچ محتوای فنی یا تأیید مجوز برای shadcn/ui وجود ندارد.، پشتیبانی پیش‌فرض از RTL و فونت وزیرمتن نیازمند تنظیمات دستی است.، هماهنگی با خروجی ایستای Next.js و تست Playwright باید جداگانه صحت‌سنجی شود.
توصیه: **shadcn/ui** — نزدیک‌ترین گزینه به استک ترجیحی مالک (Next.js + Tailwind + shadcn/ui) است و با وجود نیاز به تنظیمات RTL، کمترین فاصله را تا پیاده‌سازی سریع و تست‌پذیر میکروسایت دارد.

### فرانت‌اند (Frontend)
⭐ **Next.js** — امتیاز پذیرش: 9/10، هزینه ماهانه: ۰ تا ۲۰ دلار (میزبانی ایستا روی Vercel/Netlify در پلن رایگان یا پایه)، ریسک: پیچیدگی بیشتر نسبت به یک سایت ایستای ساده و نیاز به آشنایی با مفاهیم SSR/SSG، وابستگی به اکوسیستم React و به‌روزرسانی‌های مکرر نسخه‌ها
- **React** — امتیاز پذیرش: 10/10، هزینه ماهانه: ۰ تا ۲۰ دلار (میزبانی ایستا)، ریسک: برای خروجی ایستا نیاز به ابزار اضافی مانند Vite یا Gatsby دارد، پیکربندی RTL و فونت وزیرمتن باید دستی انجام شود
- **Vue.js** — امتیاز پذیرش: 8/10، هزینه ماهانه: ۰ تا ۲۰ دلار (میزبانی ایستا)، ریسک: اکوسیستم shadcn/ui به‌طور پیش‌فرض برای Vue وجود ندارد (نسخه‌های غیررسمی)، برای خروجی ایستا نیاز به Nuxt یا VitePress دارد
توصیه: **Next.js** — با استک ترجیحی مالک (Next.js + Tailwind + shadcn/ui) هم‌راستاست، خروجی ایستا و پشتیبانی از RTL و تست Playwright را به‌خوبی پوشش می‌دهد و بالاترین هم‌افزایی را با نیازهای این میکروسایت دارد.

### زیرساخت و سرور (Infra/Server)
⭐ **GitHub Pages** — امتیاز پذیرش: 9/10، هزینه ماهانه: ۰ تا ۴ دلار (برای مخزن عمومی رایگان؛ هزینه دامنه و در صورت نیاز پلن Pro حدود ۴ دلار)، ریسک: محدودیت نرخ و پهنای باند برای مخازن عمومی طبق شرایط GitHub، عدم پشتیبانی از منطق سمت سرور (مناسب برای خروجی ایستای Next.js)، وابستگی به اکوسیستم GitHub و سیاست‌های آن
- **Cloudflare Pages** — امتیاز پذیرش: 8/10، هزینه ماهانه: ۰ تا ۵ دلار (پلن رایگان برای پروژه‌های کوچک کافی است؛ هزینه دامنه جداگانه)، ریسک: وابستگی به شرایط سرویس و قیمت‌گذاری Cloudflare، نیاز به تنظیمات DNS در صورت استفاده از دامنه اختصاصی، محدودیت‌های ساخت (Build) در پلن رایگان
- **Netlify** — امتیاز پذیرش: 8/10، هزینه ماهانه: ۰ تا ۱۹ دلار (پلن رایگان برای شروع؛ پلن Pro حدود ۱۹ دلار)، ریسک: محدودیت پهنای باند و دقیقه‌های ساخت در پلن رایگان، هزینه‌های افزایشی در صورت رشد ترافیک، وابستگی به پلتفرم برای CI/CD و فرم‌ها
توصیه: **GitHub Pages** — برای میکروسایت ایستای کوچک با محتوای Markdown و بدون بک‌اند، GitHub Pages ساده‌ترین و کم‌هزینه‌ترین گزینه با پذیرش صنعتی بالاست و نیازهای اولیه پروژه را پوشش می‌دهد.

### هزینه و FinOps (Cost/FinOps)
