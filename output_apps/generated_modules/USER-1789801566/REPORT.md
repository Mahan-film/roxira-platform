## ۳. مدل‌سازی داده و مؤلفه‌های معماری
### موجودیت / جدول: `domain_specific_llm` (مدل زبانی حوزه‌خاص)
*مدل‌های زبانی که برای حوزه‌های خاص مانند پزشکی یا مالی آموزش دیده‌اند*

- `model_name` (string) - *unique*
- `domain` (string) - *not null*
- `accuracy` (float) - *>= 0.9*

### موجودیت / جدول: `multiagent_system` (سیستم چندعاملی)
*سیستم‌هایی که از چندین عامل هوش مصنوعی برای انجام کارهای پیچیده استفاده می‌کنند*

- `system_id` (int) - *primary key*
- `agents_count` (int) - *> 1*
- `task_complexity` (string) - *not null*
