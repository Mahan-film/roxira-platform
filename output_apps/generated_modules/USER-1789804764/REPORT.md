## ۱. ارزیابی کارشناسی و استراتژی مهندسی (پاسخ به مسئله)
سیستم‌های عامل‌محور برای تحقیقات عمیق و زنده به‌طور فزاینده‌ای در حال تبدیل شدن به ابزارهای کلیدی برای انجام تحقیقات پیچیده و چندمرحله‌ای هستند. این سیستم‌ها با استفاده از معماری‌های چندعاملی و تک‌عاملی، توانایی‌های مختلفی را برای جستجو، استخراج و ترکیب اطلاعات از منابع متنوع ارائه می‌دهند. سیستم‌های چندعاملی به دلیل توانایی در تجزیه و تجمیع وظایف، عملکرد بهتری در کیفیت گزارش‌ها و قابلیت اطمینان دارند. پلتفرم‌هایی مانند MiroFlow، SciResearcher و DeerFlow با استفاده از مدل‌های پیشرفته مانند GPT-5، Claude 3.7 Sonnet و Qwen3-8B، قابلیت‌های تحقیقاتی را به سطح جدیدی ارتقا داده‌اند. این سیستم‌ها از روش‌های مختلفی مانند Prompting، REINFORCE، PPO و GRPO برای بهینه‌سازی عملکرد استفاده می‌کنند. زیرساخت‌های مورد نیاز شامل سرورهای محلی یا ابری، ابزارهای جستجوی وب و پایگاه‌های داده محلی است.

## ۴. مدل‌سازی داده و مؤلفه‌های معماری
### موجودیت / جدول: `language_model` (مدل زبانی)
*مدل‌های زبانی بزرگ برای پردازش و تولید متن*

- `model_name` (string) - *unique*
- `version` (string) - *not null*
- `parameters` (integer) - *not null*

### موجودیت / جدول: `search_tool` (ابزار جستجو)
*ابزارهای جستجوی وب برای استخراج اطلاعات*

- `tool_name` (string) - *unique*
- `version` (string) - *not null*
- `api_endpoint` (string) - *not null*

### موجودیت / جدول: `database` (پایگاه داده)
*پایگاه‌های داده محلی برای ذخیره‌سازی و بازیابی اطلاعات*

- `db_name` (string) - *unique*
- `version` (string) - *not null*
- `size` (integer) - *not null*
