## 1. Pure rules: purchasing/invoice-match.domain.ts (+ invoice-match.domain.spec.ts)
Types: MatchStatus = 'MATCHED' | 'QTY_MISMATCH' | 'PRICE_MISMATCH' | 'QTY_AND_PRICE_MISMATCH'. Invoice line input: {receiptLineId, quantity: bigint hundredths, unitPrice: bigint minor}.
`matchInvoiceLine({orderUnitPrice, receivedQuantity, alreadyInvoicedQuantity, quantity, unitPrice}, settings)` returns {status, qtyExcess: bigint (0n if none), orderValue, invoiceValue, priceDifference: bigint (invoiceValue - orderValue, signed)}.
- orderValue = lineValue(quantity, orderUnitPrice), invoiceValue = lineValue(quantity, unitPrice) (existing lineValue, half up).
- Quantity mismatch when alreadyInvoicedQuantity + quantity > receivedQuantity (qtyExcess = the excess).
- Price tolerance for the line: allowed = max( floor(orderValue * priceToleranceBp / 10000), priceToleranceAbs ) (bigint math, settings from DEFAULT_PURCHASE_SETTINGS shape; undefined means 0). Price mismatch when abs(priceDifference) > allowed (strictly greater).
`matchInvoice(lines)` -> overall status: 'MATCHED' only when every line MATCHED else 'HELD'.
`invoicePostingTotals(lines, vat)`: grniDebit = sum orderValue, varianceNet = sum priceDifference (positive = debit PRICE_VARIANCE, negative = credit), vat, payable = sum invoiceValue + vat.
Hand-computed spec cases (use exactly these): order price 5000000, received 1000, already 0, invoice qty 1000 @5000000 -> MATCHED, diff 0. Same qty @5100000: invoiceValue 51000000, orderValue 50000000, diff 1000000; with bp 100 abs 0: allowed 500000 -> PRICE_MISMATCH; with bp 100 abs 1000000: allowed 1000000, diff not greater -> MATCHED; with bp 200 (allowed 1000000) -> MATCHED; bp 199 -> allowed 995000 -> PRICE_MISMATCH. Invoice qty 1100 with received 1000 -> QTY_MISMATCH qtyExcess 100. received 600, already 400, qty 300 -> QTY_MISMATCH qtyExcess 100; qty 200 -> MATCHED. Price below order @4900000 qty 1000: diff -1000000, with bp 0 abs 0 -> PRICE_MISMATCH. Both problems -> QTY_AND_PRICE_MISMATCH. invoicePostingTotals for one line qty 1000 @5100000 vat 4590000 -> grniDebit 50000000, varianceNet 1000000, payable 55590000.
